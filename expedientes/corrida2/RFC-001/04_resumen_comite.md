# Resumen para el Comité — RFC-001

**Qué se pide:** Cambio sobre REPORTES; solicitud completa, sin campos faltantes, con ventana propuesta el sábado de 9:00 a 10:00.
**Impacto:** Afecta directamente solo REPORTES (criticidad Baja). Ningún sistema afectado indirectamente.
**Riesgo:** Bajo. El requisito de ventana no aplica (de todos modos cae fuera de horario hábil). No se exige aprobación del comité completo.
**Qué debe decidir el comité:** Si aprueba el cambio de riesgo bajo en la ventana propuesta.
