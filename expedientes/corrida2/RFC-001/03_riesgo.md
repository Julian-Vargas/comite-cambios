# Acta de Riesgo — RFC-001

- **Corrida:** corrida2
- **Nivel de riesgo:** Bajo
- **Regla aplicada:** "**BAJO** — Todo lo demás." (Política, sección 2). No aplica ALTO porque ningún sistema afectado, ni directo ni indirecto, tiene criticidad alta. No aplica MEDIO porque ningún sistema afectado tiene criticidad media.
- **Sistema que determina el nivel:** REPORTES — criticidad Baja (afectado directamente; no hay sistemas afectados indirectamente)
- **Ventana propuesta:** Sábado, de 9:00 a 10:00
- **¿La ventana cumple la política?:** No aplica — la política solo exige ventana fuera de horario hábil para cambios de riesgo ALTO. (La ventana propuesta, en sábado, cae de todos modos fuera del horario hábil.)
- **Aprobación requerida:** No se exige la aprobación del comité completo; la política solo define requisitos adicionales de aprobación para cambios de riesgo ALTO.
