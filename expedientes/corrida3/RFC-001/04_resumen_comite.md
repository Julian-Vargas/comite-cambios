# Resumen para el Comité — RFC-001

**Qué se pide:** Cambio que afecta al sistema REPORTES. Solicitud completa, sin campos faltantes; ventana propuesta: sábado de 9:00 a 10:00.
**Impacto:** Directo sobre REPORTES (criticidad Baja). Ningún sistema afectado indirectamente.
**Riesgo:** Bajo (Política, sección 2). Requisitos de ventana no aplican a riesgo bajo; la ventana cae fuera del horario hábil.
**Qué debe decidir el comité:** Aprobar o rechazar el cambio. La política no exige aprobación especial ni comité completo para riesgo bajo.
