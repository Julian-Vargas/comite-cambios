# Acta de Riesgo — RFC-003

- **Corrida:** corrida3
- **Nivel de riesgo:** Medio
- **Regla aplicada:** "MEDIO: El cambio afecta un sistema de criticidad media." (POLITICA_CAMBIOS.md, sección 2). No aplica ALTO porque ningún sistema afectado, directo (AUTH-CORE, Media) ni indirecto (INTRANET, Baja), tiene criticidad alta.
- **Sistema que determina el nivel:** AUTH-CORE — criticidad Media (afectado directamente)
- **Ventana propuesta:** Jueves, de 10:00 a 10:30
- **¿La ventana cumple la política?:** No aplica — la política solo exige una ventana fuera de horario hábil para cambios de riesgo ALTO. La ventana propuesta cae en horario hábil (jueves entre 8:00 y 17:00), lo que no está restringido para riesgo Medio.
- **Aprobación requerida:** La política no establece un requisito de aprobación específico para riesgo Medio (la aprobación del comité completo solo es obligatoria para riesgo ALTO).
